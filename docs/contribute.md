# 参与贡献

## 补充经验

欢迎提交新的知识、维修案例，或修正已有内容。先说明问题和适用环境，再给出过程、结果与参考资料。

## 从帖子到文章

有具体问题时先在[飞扬论坛](https://forum.feiyang.ac.cn)中讨论。经过验证的解法可以整理进相关文章，并保留原帖链接。

## 提交修改

- 小修正可点文章右上角的编辑按钮，在 GitHub 发起 Pull Request。希望维护者先看一眼时，也用 Pull Request。
- 已获仓库写权限的维护者可用 [Sveltia 在线编辑](/admin/index.html)。保存到主分支会触发 Wiki 构建。
