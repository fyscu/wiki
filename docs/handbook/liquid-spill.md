# 笔记本进水急救

在日常生活中，经常会遇到由于不小心等原因，将水洒到笔记本上的问题。如果没有此类问题的处理经验，很多人会选择反复开关电源试图重新启动系统。殊不知，此类操作是最危险的，往往由于此类操作会导致笔记本主板烧毁，甚至整台机器报废。

## 关机并拔下电源

立即关机，从电脑端拔下电源线和外接设备。电池可从机身外直接拆取时，可以取下电池。内置电池由熟悉该机型的人员按维修手册处理。

## 清除表面水渍

判定一下进水的方向，看看水是直接洒到键盘上的还是从桌面上流过来的。用干燥软布吸走表面的液体，避免按动键盘或摇晃机身。没有处理经验时，余下的工作请联系售后或维修人员。

## 送检与备份

如果流入水量比较多，或是洒到笔记本上的液体是豆浆、咖啡之类的东西，则必须交由专业处理人员进行处理。即使外表已经干了，内部仍可能有液体或残留物。送检前不要充电、开机或用吹风机加热。有重要资料时，交机时先说明优先保数据。
