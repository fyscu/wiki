# 计算机启动与排障

「开不了机」可能指完全没有通电迹象，也可能是电脑有画面却进不了系统。先记下**最后一个看得见的阶段和完整提示**，再找对应问题。

| 现场现象 | 先检查什么 | 下一步 |
| --- | --- | --- |
| 完全没有灯光、风扇或声音 | 插座、充电器、电源线和台式机电源开关 | 用匹配的电源排除外部供电问题。闻到焦味、有进液或看到电池鼓包时，断开外接电源，停止尝试开机 |
| 有指示灯或风扇，屏幕始终无画面 | 显示器输入源、线缆、诊断灯或蜂鸣声 | 用外接屏或其他线缆交叉判断，有诊断代码时查对应型号的说明 |
| 能看到厂商标识，出现「找不到启动设备」 | 能否进固件菜单，能否识别系统盘，启动顺序是否变化 | 先参照[启动链、BIOS 与固件设置](firmware-and-boot.md)，核对[引导模式与分区表](power-states-uefi.md) |
| 已出现系统标志、转圈或错误代号 | 记录蓝屏或恢复提示，回想最近的更新、迁移或换盘 | 在系统恢复环境中检查启动错误 |
| 合盖、休眠后黑屏，正常关机后可开机 | 看[睡眠、休眠与引导](power-states-uefi.md)中的电源状态 | 记录唤醒方式、供电状态和是否接着外设，帮助区分唤醒与冷启动 |
