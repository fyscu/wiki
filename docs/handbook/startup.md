# 计算机启动与排障

先确定启动停留在哪个阶段，再检查对应部件和配置。

## 启动的几个阶段

| 阶段 | 通常能观察到的现象 | 检查方向 |
| --- | --- | --- |
| 加电 | 电源灯亮，风扇开始转动 | 电源适配器、供电接口、电池及主板 |
| 自检 | 厂商标识、蜂鸣声或诊断灯 | 按机型手册检查内存、显示和设备状态 |
| 引导 | 找到系统启动项并加载引导程序 | 存储设备识别、启动顺序、引导配置 |
| 系统启动 | 系统标识、加载动画、登录界面 | 驱动、更新、系统文件和存储健康 |

## 没有任何通电迹象

检查插座、电源线、适配器和接口，记录指示灯与断电情况。进液设备应先断电、保持关机，并交由维修人员处理。

## 能显示厂商标识，但进不了系统

在固件设置中检查系统盘识别、启动模式和启动项，核对近期修改。

初始化磁盘、格式化或调整控制器模式前，先备份数据并核对操作方案；加密设备同时保存恢复密钥。

## 已开始加载系统，随后报错

记录错误代码、发生阶段和近期驱动、更新变更，进入恢复环境诊断。重装系统前先备份数据。

## 提问信息

- 设备型号与系统版本。
- 按下电源键后最后出现的画面或错误代码。
- 故障前是否更新、拆装、断电或接触过液体。
- 已经尝试过的操作及每一步的结果。
