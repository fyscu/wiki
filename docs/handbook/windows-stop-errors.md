# Windows 蓝屏排查

先拍下停止代码和屏幕上出现的模块名，记下故障前安装过的驱动、软件或硬件。若屏幕一直黑着、从未显示停止代码，请参见[计算机启动与排障](startup.md)。

## 内存条接触不良或内存损坏导致电脑蓝屏

检查近期是否换过内存。先用内存诊断工具确认，必要时关机断电，并按设备手册重新插好内存条。如果问题没有解决并确定是内存故障，更换内存条。

## 硬盘出现故障导致电脑蓝屏

硬盘出现问题也经常会导致电脑蓝屏，比如硬盘出现坏道，电脑读取数据错误导致蓝屏。我们可以检测硬盘坏道情况，如果硬盘出现大量坏道，建议备份数据更换硬盘。如出现读写错误或坏道，优先备份数据并检查硬盘健康。格式化不能修复硬盘的物理损伤。

## 安装的软件不兼容导致电脑蓝屏

卸载掉后来安装的软件，或者使用Windows 系统还原功能，直接将系统恢复至上一个还原点进行检测。

## 中病毒导致的电脑蓝屏故障

有些病毒木马会感染系统文件，造成系统文件错误，或导致系统资源耗尽，也可能造成蓝屏现象的发生。发现电脑出现蓝屏现象，下次重新启动电脑后可进行杀毒操作，建议选用目前主流的杀毒软件查杀，如果遇到恶意病毒，建议系统还原或者重新安装系统。

## 电脑温度过高导致电脑蓝屏

多出现在炎热的夏天，CPU 温度过高导致的居多，温度过高主要以CPU 与显卡，硬盘等做重要参考。检测硬件的温度，如果是CPU 或显卡温度引起，那么开机看CPU 风扇和显卡风扇是否正常转动，正常的话建议加强主机散热，比如添加机箱散热等，如果是硬盘温度过高，则可能有硬盘故障，需要更换。

## 其他原因导致的电脑蓝屏

其他原因方面，比如电脑电源出现故障，导致供电不正常，导致经常死机等，还有的是电脑硬件不兼容，这种情况多数出现在新购买的组装电脑上，遇到这种情况大家可以在网上搜索相关硬件信息，购买组装电脑尽量去选择搭配均衡，兼容性好的硬件搭配。
