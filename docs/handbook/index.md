# 维修知识

## 启动与引导

- [计算机启动与排障](startup.md)：识别启动阶段，判断应该检查供电、固件、引导还是操作系统。

## 排查思路

先记录现象和最近的变化，再选择能验证判断的操作。每次改变一个条件，保留结果，避免连续修改多个设置后无法复现。

需要讨论具体情况时，可以在[知识问答](../questions.md)中补充设备型号、错误信息和已经尝试的步骤。
